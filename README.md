This repository discloses US Emergency Alert System exposure using the Shodan search engine.

This project is an exercise of Free Speech under the US Constitution First Amendment.

Attempts from 2012 onward through 2026 to reduce EAS public Internet exposure have proven mostly unsuccessful time and time again.   Mostly.

Refer to media coverage from 2013 and 2020.

Congressional committee reports and transcripts wrt past "zombie" EAS alerts are out-of-scope for this archive, but recommended reading for full-scope background from 2010 onward. 

Repository contains URLs for Shodan searches, FCC comments wrt security posture recommendations, URLs to prior media coverage, eBay "EAS for sale" examples to illustrate supply-chain and adversary acquisition risks, distribution by ISP and .edu and sundry screenshots as appropriate.

Note no direct IP addresses are disclosed, other than in sample EAS screenshots to illustrate real-world exposure and web interface characteristics.  Further barriers to potential misuse of these data entail Shodan itself requiring a registered account for basic searches, and a paid-tier account for more expansive search capability, of which I recommend (I have no financial tie to Shodan).
